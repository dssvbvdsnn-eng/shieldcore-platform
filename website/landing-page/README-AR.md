# ShieldCore — الموقع التعريفي

هذه النسخة هي صفحة التعريف العامة للمشروع، وهي مستقلة عن لوحة التحكم الموجودة في المجلد الشقيق `website/`، ولم يتم استبدال ملفات لوحة التحكم.

## تشغيل محلي

من هذا المجلد شغّل:

```bash
python -m http.server 8080
```

ثم افتح `http://localhost:8080`. يلزم تشغيله عبر HTTP/HTTPS لأن الصفحة تحمّل ملفات CSS وJavaScript المضغوطة عند التشغيل.

## محتويات المجلد

- `index.html`: الصفحة الرئيسية العربية.
- `loader.js`: يفك ضغط ملفات الواجهة عند التشغيل باستخدام GZIP.
- `styles.css.gz`: ملف التصميم.
- `script.js.gz`: الأنيميشن، عناصر الواجهة، ومحاكاة المعاملات.
- الشعار والأيقونة يعاد استخدامهما من `../assets/shieldcore-mark.png`.

لتحرير CSS وJavaScript محليًا، فك الضغط باستخدام:
```bash
gzip -dk styles.css.gz script.js.gz
```

## النشر

- في Cloudflare Pages اضبط مجلد النشر (Output directory) على `website/landing-page`.
- هذه صفحة Front-end ثابتة، ومحاكاة المعاملات توضيحية فقط؛ ليست متصلة بمحرك كشف احتيال حقيقي أو Backend.
- أرقام 99.4% و12ms و42% و85% معروضة كمستهدفات واردة في تقرير المشروع، وليست نتائج تشغيلية مثبتة.
